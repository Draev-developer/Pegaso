# Pegaso 0.5.1

Versión de mejora de Pegaso, el cliente P2P libre para Windows que descarga de las redes eMule (eD2K y Kad), de BitTorrent y de la web desde una sola lista.

## Descarga

**`Pegaso-0.5.1-setup.exe`** — instalador para Windows 10 y 11 de 64 bits. No necesita permisos de administrador. Se instala encima de versiones anteriores y conserva la configuración y las descargas.

## Novedades

- **Mover vídeos sin esperas.** Al renombrar y mover muchos archivos, o archivos grandes a otro disco, Pegaso ya no se queda parado: los mueve uno tras otro en segundo plano, con una barra de avance, y puedes seguir usando el programa mientras tanto.
- **Los archivos de torrents también van a otro disco**, y se siguen sembrando desde allí.
- **Pantalla de arranque** con el autor de Pegaso junto al aviso de eMule.

Lo demás es lo de la [0.5](https://github.com/Draev-developer/Pegaso/releases/tag/v0.5). La lista completa está en [CHANGELOG.md](https://github.com/Draev-developer/Pegaso/blob/main/CHANGELOG.md).
