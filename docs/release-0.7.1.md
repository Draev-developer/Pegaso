# Pegaso 0.7.1

Pegaso es el cliente P2P libre para Windows que descarga de las redes eMule (eD2K y Kad), de BitTorrent y de la web desde una sola lista. *English below.*

## Descarga

- **`Pegaso-0.7.1-setup.exe`** — instalador para Windows 10 y 11 de 64 bits. No necesita permisos de administrador. Se instala encima de versiones anteriores y conserva la configuración y las descargas. Incluye la extensión.
- **`Pegaso-0.7.1-extension-chromium.zip`** y **`Pegaso-0.7.1-extension-firefox.zip`** — la extensión sola (no cambia respecto a la 0.6).

## Qué cambia

- **Añadir un torrent a una descarga de eMule, sin escribir rutas.** «Añadir un torrent de este mismo archivo…» abre una ventana con un botón **Examinar** y una lista de lo que Pegaso ha encontrado por su cuenta: los torrents de la lista de descargas y los archivos `.torrent` de tus carpetas de descargas que tienen un archivo de exactamente el mismo tamaño. Si solo hay uno, ya viene elegido.
- **Un torrent de la lista como fuente.** Un torrent que ya está en la lista puede dar sus datos a una descarga de eMule del mismo archivo sin dejar de ser una descarga propia.
- **Lista de servidores de serie actualizada**: 19 servidores eD2K en lugar de 9, para quien empieza con la lista vacía.

La lista completa está en [CHANGELOG.md](https://github.com/Draev-developer/Pegaso/blob/main/CHANGELOG.md).

---

## English

- **Adding a torrent to an eMule download without typing paths.** "Add a torrent of this same file…" opens a window with a **Browse** button and a list of what Pegaso has found by itself: the torrents of the download list and the `.torrent` files of your download folders which have a file of exactly the same size. If there is only one, it comes chosen already.
- **A torrent of the list as a source.** A torrent which is in the list already can give its data to an eMule download of the same file without ceasing to be a download of its own.
- **The built-in server list is up to date**: 19 eD2K servers instead of 9, for whoever starts with an empty list.

The whole list is in [CHANGELOG.en.md](https://github.com/Draev-developer/Pegaso/blob/main/CHANGELOG.en.md).
